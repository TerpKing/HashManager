# Hash Management Application

The Hash Management Application is a simple web application built with Flask that allows users to manage hashes efficiently. 

- **Add Hashes**: Users can input hash values to add them to the list.
- **Import Hashes**: Users can upload a text file containing hashes to import them into the application.
- **Search Hashes**: Users can search for a specific hash to check if it exists in the list.
- **Compare Hashes**: Users can compare a hash against another hash to find matches.
- **Compare Two Hashes**: Users can check if two hashes are equal.
- **Export Hashes**: Users can download all stored hashes as a text file.

## Technologies Used

- **Flask**: A lightweight WSGI web application framework in Python.
- **ReportLab**: A library for generating PDFs (not used in this version but included for potential future features).
- **HTML/CSS**: For the front-end user interface.

## Requirements

- Python 3.x
- Flask
- ReportLab


Install and run:

git clone https://github.com/yourusername/hash-management-app.git

cd HashManager

pip install -r requirements.txt

python app.py
